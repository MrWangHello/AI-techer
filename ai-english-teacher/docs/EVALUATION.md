# Bella 项目评测方案与评分

> 目的：用可复现的标准给产品打分，并排出改进优先级。  
> 功能清单：[`FEATURES.md`](./FEATURES.md) · 用例：[`TEST_CASES.md`](./TEST_CASES.md)  
> 目录源码：`src/lib/eval/feature-catalog.ts`

评测日期：2026-08-30  
评测对象：GitHub Pages 静态 Web 应用（无后端、无 LLM）  
使用情境：1–3 年级儿童 + 家长代操作；手机 Chrome 为主

---

## 1. 评测方法从哪里来

综合了公开标准，再裁剪到本项目「语音优先、儿童、零后端」：

| 来源 | 用什么 |
|------|--------|
| **ISO 9241-11** | 有效性 / 效率 / 满意度（必须放在使用情境里评） |
| **ISO 9241-110** | 任务适合、自描述、容错、可学习 |
| **Nielsen 启发式** | 系统状态可见、匹配真实世界、防错、帮助与文档 |
| **Google HEART** | Task success 可自动化；Happiness/Retention 本阶段用专家评代替埋点 |
| **T/CCSA 490-2024** | 语音交互：响应是否完成任务、弱网是否失败 |
| **儿童信息搜索可用性研究** | 语音输入对儿童通常比打字更有效；必须有明确引导 |

本项目**不做**的评测（当前不具备条件）：真机儿童 CER、SUS 问卷、留存埋点。这些记为「下一阶段」。

## 2. 评分量表（每维 0–5）

| 分 | 含义 |
|----|------|
| 5 | 达到承诺，有自动化用例，弱网可用 |
| 4 | 主路径可用，次要缺口 |
| 3 | 能用但不稳或引导不足 |
| 2 | 半成品或承诺与行为不符 |
| 1 | 几乎不可用 |
| 0 | 缺失 |

**综合分** = 六维加权平均 × 20，得到百分制。

| 维度 | 权重 | 本轮得分 | 加权 |
|------|------|----------|------|
| A 功能完整度（对照承诺） | 20% | 3.2 | 0.64 |
| B 语音任务成功率 | 25% | 3.6 | 0.90 |
| C 稳定与离线 | 20% | 3.7 | 0.74 |
| D 自动化测试覆盖 | 15% | 3.6 | 0.54 |
| E 儿童可用性（引导/兜底） | 15% | 3.3 | 0.50 |
| F 内容深度 | 5% | 2.6 | 0.13 |
| **综合** | 100% | | **3.45 / 5 → 69 分** |

等级：**可用原型（C+）**，未到「可放心给一年级独立使用」的产品线。

## 3. 分维说明

### A 功能完整度 3.2

- 五科学习壳、口算、本地词典、故事/古诗、百科兜底、宠物互动、语速试听已落地
- **broken：** 应用题 hint 说可以语音答题，实际不判题
- **partial：** 「测验/考我」不进测验 UI；天气点击不查询；每日英语双数据源
- **placeholder：** 装扮
- 语文.故事与阅读.故事语音路由分裂

### B 语音任务成功率 3.6

- catalog 驱动测试：约 48 条短语命中期望 intent（`feature-catalog.test.ts`）
- 口算模式守卫、查词本地化后不再因外网崩溃
- 未测：真机 STT（儿童口音 / 无 GMS 机型）
- 部分手机 TTS `rate` 无效

### C 稳定与离线 3.7

- 词典、古诗、故事、口算、wiki snippets **可离线**
- 天气、每日英语 API **弱网失败**（有部分兜底）
- 历史问题：词霸查词导致错误页 —— 已改为本地词库
- 视频首屏仍可能占带宽

### D 测试覆盖 3.6

- 单元：意图目录、口算、查词、wiki、normalize
- E2E：文字模拟语音 + Tab 完整性
- 缺：签到/成就状态、测验 UI、设置改名、真 TTS

### E 儿童可用性 3.3

- 各学习分区有「🎤 语音这样说」
- 底部麦克风文案明确
- 设置页仍无 VoiceHintBar
- 探索 Tab 点击只有提示，儿童可能不知道还要说话
- 帮助回复偏长，一年级难以听完

### F 内容深度 2.6

- 汉字 20、故事约 6、笑话 7、短诗 8 —— 重复快
- `stories.json` 英文故事未接入
- 词库 187 对「任意中文怎么说」仍经常 miss

## 4. Nielsen 启发式速检

| 启发式 | 判断 | 问题 |
|--------|------|------|
| 系统状态可见 | 中 | 聆听/思考有状态；情绪不自动回中性 |
| 匹配真实世界 | 中 | 「今日学习」实为累计；应用题 hint 说谎 |
| 用户控制 | 良 | 可停口算、可切文字 |
| 一致性 | 差 | 讲故事 vs 语文故事 Tab；每日英语两套内容 |
| 防错 | 中 | 口算守卫好；查词 miss 有提示 |
| 识别而非记忆 | 中 | 有 hint，设置页没有 |
| 灵活高效 | 良 | 语音直达学科 |
| 简约 | 良 | 四 Tab |
| 容错 | 中 | STT 纠错有，儿童口音无 |
| 帮助 | 中 | 有「帮助」，偏长 |

## 5. 改进 backlog（按评测优先级）

### P0 — 承诺与行为必须一致（否则扣分最狠）

1. 应用题：实现语音/文字判题，或改掉「请说答案」hint
2. 「测验/考我」进入 StudyCards quiz 模式，或改回复「请点开始测验」

### P1 — 语音任务闭环

3. 统一「讲故事」与语文/阅读故事入口（或 hint 写清）
4. 探索 Tab 点击即出一条天气/百科示例，不要只留提示
5. 设置页加上 VoiceHintBar
6. 帮助回复缩短为一年级可听完的 3–4 条

### P2 — 内容与数据

7. 扩充故事/笑话/词库 miss 高频词
8. 接入或删除闲置 `stories.json`
9. 清数据同时清 `bella_word_batch`
10. 成就阈值与词库规模对齐

### P3 — 体验

11. agentEmotion 数秒回 neutral
12. 互动 feed 写入 localStorage
13. 真机 STT/TTS 检查清单（人工）

## 6. 如何复评

```bash
cd ai-english-teacher
npm run test:all
```

1. 跑 `feature-catalog.test.ts`：语音短语命中率（自动化 Task success）
2. 更新 catalog 里 `status` 后重算 §2 表格
3. P0 清零前，综合分不宣称 ≥80

下一阶段可加：真机 10 条儿童任务（成功率、完成时间、是否求助家长）= ISO 有效性/效率。
