# 手机排版与点读方案（一年级）

状态：已实现（学习页点读 + 侧栏对话 + 瘦壳）  
线上问题：大字 + 大喇叭 + 顶栏对话 + 高底栏叠在一起，小屏又挤又花，回复条右侧像叠层。

---

## 1. 目标

一屏只突出 **正在学的字 / 课文**。  
不认识的字仍然能听：点字或点这一行就出声。  
对话、统计、说明、次要操作全部弱化，靠图标认，认过一次就记住。

不改：Skill 路由、宠物数据、知识库、Cat3D 视频、浏览器 SpeechSynthesis（不接未配置的 Worker）。

---

## 2. 一屏结构

```
┌─────────────────────────┐
│ 学习              🪙99  │  细顶栏一行
│ 英语 语文 数学 …        │  主学科芯片（图标 + 汉字 + 原有拼音）
│                         │
│                         │
│        目               │  主舞台：一个字 / 一篇课文
│        mù               │
│                         │
│                    💬你 │  侧边浮条，只露一行
│         ( 🎤 )          │  大麦，无说明字
│  🏠    🐱    📖    ⚙️   │  图标 + 两个汉字，无拼音
└─────────────────────────┘
```

纵向只留三层壳：顶栏、主舞台、底栏（麦 + 导航）。  
对话不再占顶栏和内容之间的整条带宽。

---

## 3. 谁大谁小

| 层级 | 是什么 | 怎么显示 |
|------|--------|----------|
| 主 | 当前字/词/课文；学科切换 | 字大、卡大；芯片用大图标 + 汉字 + **原来就有的拼音** |
| 次 | 换一个、显示意思、喂食/玩/洗/睡、签到 | 图标一眼能认，字缩小或只留 2 字 |
| 弱 | 「可以这样说」、操作说明、学习统计 | 默认收起；统计回首页或顶栏小图标打开 |

记忆靠位置和图标：底栏从左到右永远是首页 / 宠物 / 学习 / 设置（图标 + 两个汉字，不再加拼音，省高度）。

**拼音规则：**

- **汉字尽量带拼音。** 主字下面放大拼音（`目` / `mù`）；成语、组词等数据里已有拼音的都显示，而且要比现在更大、更清楚。数据里没有拼音的长文（故事、古诗）先不造拼音库，靠点读听。
- **主学科保留原拼音。** 英语 yīng yǔ、语文 yǔ wén、数学 shù xué、阅读 yuè dú、探索 tàn suǒ（已有 `SUBJECT_PINYIN`）继续写在芯片上，字可以略小，但不要删。
- 麦克风、次要按钮不加拼音。

## 4. 点读：小喇叭 + 整块热区

业界（识字卡、点读笔圈码、Duolingo ABC、儿童阅读 TTS）：  
**小喇叭 =「这里能出声」；手指点的是字或整行，不是图标本身。**

### 4.1 视觉与热区

- 图标：约 16–18px，贴在字角或行尾，同一形状，认一次即可。
- 热区：整块字、整行（含拼音、组词、例句）。点字、点行内空白、点小喇叭，都朗读这一段。
- **操作就是点一下。** 不要滑、不要长按。点一下出声，再点一下停。孩子不用对准小喇叭。
- 实现用普通点击（`onClick`）。页面照常可以上下滑；滑页时浏览器本身不会当成点击，不必再做「滑了几像素就取消」这种手势，免得难操作。
- 按下：这一行浅粉底 + 喇叭变「正在响」。
- 不要写「点击喇叭朗读」。不自动播。孩子点一下就会响。

### 4.2 哪些能点

| 内容 | 热区 | 读什么 |
|------|------|--------|
| 主字（目） | 整个大字（字下显示拼音） | 这个字 |
| 拼音 / 组词 / 例句 | 各一行 | 这一行 |
| 故事 / 古诗 | 按句或按行 | 这一句，不要一篇只有一个热区 |
| 英文单词 | 单词一块 | 英文音 |
| 中文释义 | 释义一行 | 中文音 |
| 口算情景 / 算式 | 各一块 | 读题，不读键盘 |
| 对话展开后的 Bella 行 | 整行 | 这一句 |

中英：纯拉丁走 `speakEnglish`，带汉字走中文音（已有 `speakAuto`）。

### 4.3 测验（热区必须拆开）

轻点选答案，不能同时触发朗读。

- 选项字面 = 答题。
- 右上角小喇叭 = 只朗读；热区只包住小图标，不包整颗选项。
- 不用长按（一年级不稳）。

口算：数字键只输入，不朗读。

### 4.4 实现要点

新组件（替换现在 48px `SpeakIcon` 旁挂）：`SpeakableLine` / 可点主字。

- 整行 `button` 或 `role="button"`，`aria-label="朗读 …"`，绑定 `onClick`：点一下就读。
- 行内小 `Volume2`，`pointer-events-none`（避免抢点击）。
- 开新的朗读前 `stopSpeaking()`。

学习卡、回复展开层都走这套。删掉「每行一颗大粉圆 + 底下再一颗朗读全部」的重复。

## 5. 对话：侧边一行浮条

「你 讲故事」+ Bella 长文不再钉在标题下面，也不并排两颗大喇叭 + ✕。

- **收起（默认）：** 贴右侧（垂直居中偏下，避开大字和麦克风）。一条 pill，只显示一行：`你 讲…` / `Bella 小兔…`（谁 + 开头两三字）。
- **展开：** 点浮条，右侧滑出或底上滑半屏。全文 + 可点读行 + 关闭。点遮罩或再点浮条收回。展开是浮层，不撑开页面。
- **不想看：** 不点浮条，照样对麦克风说。新回复只改 pill 上几个字。
- **和课文分工：** 「讲故事」之后，全文只在学习卡出现一次。浮条是摘要，课卡是正文。禁止两边各铺一遍全文。
- **在首页说话、没有课卡时：** 展开浮层里看全文（这是唯一正文）。

顶栏永远只有：当前 Tab 短名 + 金币（及签到等一个次要图标）。

---

## 6. 底栏与次要按钮

- 麦克风：中间只留大圆麦。去掉「点击说话 · 长按连说」和底下说明行。听的时候变红波纹，状态靠形状。
- 左侧键盘图标保留（业界已认）。
- 导航：图标 + 两个汉字，去掉拼音和选中大色块堆叠。
- 宠物四动作：大图标，标签缩小。
- 「换一个 / 显示意思」：刷新 / 眼睛，文字缩小。
- 「可以这样说」：学科旁小问号，点开才出，不常驻粉条。

滚动区底部留白（大约麦 + 导航的高度），最后一张卡能滑到麦上方，不再被白底栏切掉。

学习统计：移出学习主舞台，回首页或顶栏小图表打开。

---

## 7. 各 Tab 落点

- **学习：** 学科芯片 + 一块课 + 点读热区 + 侧边浮条。无统计、无重复故事、无常驻提示条。
- **首页：** 总览和统计放这里；快捷入口保持大图标磁贴（主入口）。
- **宠物：** 猫 + 四个图标动作；对话同样走侧边浮条。
- **设置：** 已经偏大字，次要说明可再收；家长页不必每行点读。

## 8. 整体再看：还没完全消掉的问题

实现前必须按下面处理，否则还会乱或点错。

1. **点一下就出声**  
   不搞滑动手势、不搞长按。用普通点击即可；滑页面时本来就不会触发点击。

2. **浮条挡字 / 挡麦**  
   右侧 pill 不能盖住主字和麦克风。主字居中略偏左，浮条贴右缘；无对话时浮条不出现。

3. **测验点读和答题抢点击**  
   已规定拆热区。做的时候用 e2e 锁住：点选项字面只改对错，不依赖朗读。

4. **底栏四个字没有拼音**  
   学科芯片保留拼音；底栏只靠图标位置记。不加回底栏拼音，以免再顶高。

5. **自动试读可能没声**  
   浏览器常拦自动播放。第一次只做高亮示范，等孩子自己点再出声。TTS 仍是本机 `SpeechSynthesis`，部分环境会静音，和这次排版无关。

6. **首页本身仍可能偏满**  
   这次主攻学习页（你截图那一屏）。首页英雄卡 + 入口 + 统计可以第二轮再收，避免一次改太散。

7. **展开对话盖住课文**  
   这是故意的：看对话时课文在底下。必须一键关掉，关掉后课文完整在。

8. **自动化测试选择器**  
   现在不少 e2e 找 `button` 名「朗读」。改成整行可点后，要用 `getByRole('button', { name: /朗读/ })` 或给主字加稳定 `aria-label`。测过一次就要改测试，不能等线上再炸。

9. **弱网 / 静态站**  
   不加新字体包、不大图。小喇叭用现有 Lucide。

---

## 9. 实现顺序

1. `SpeakableLine`：小图标 + 整行可点，**点一下出声**；汉字尽量带大拼音；学习卡、口算题干换上去。  
2. 侧边一行对话浮条 + 展开层；撤掉顶栏下的 `VoiceReplyBar` 整条带宽。课卡与回复不再重复全文。  
3. 学习页去掉统计和常驻提示；学科芯片保留原拼音；底栏去说明字、导航去拼音。  
4. 次要按钮改图标优先。  
5. 补 e2e；本机 + 线上小屏再走一遍学习 / 讲故事 / 测验。

每步可单独看：先点读不挤，再对话不挡，再壳变瘦。
