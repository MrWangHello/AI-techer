# 小学 1–3 年级内容规划（生动活泼版）

> 状态：**规划稿** — 默认年级 **一年级**，可升到二、三年级  
> 关联：[APP_PRODUCT_PLAN.md](./APP_PRODUCT_PLAN.md) · [MODULE_FEASIBILITY.md](./MODULE_FEASIBILITY.md)  
> 课标参考：部编版一年级上册（2024）、人教 PEP 三年级上册  
> 日期：2026-08-30

---

## 1. 设计总原则

| 原则 | 说明 |
|------|------|
| **年级** | 默认 **一年级**；设置可选 1 / 2 / 3 年级，难度自动切换 |
| **Tone** | 生动、活泼、有趣 — Bella 像陪读小伙伴，不是严肃老师 |
| **多感官** | 大字 + 表情/插图 + TTS 朗读 + 语音答题 + 宠物反馈 |
| **短平快** | 单题/单句 10–30 秒；连对奖励 🪙，答错鼓励不打击 |
| **图文并茂** | 汉字配象形图；算式配水果/动物 emoji；英语配场景小图 |

**Bella 话术风格：**

```
✅ 「哇！3 加 5 等于 8，你太棒啦！」🎉
✅ 「apple 就是苹果呀，红红的，甜甜的~」🍎
❌ 避免：「错误。请重新作答。」
```

## 2. 语文 — 拼音 · 汉字 · 句子

> 用户要求：**语文就按拼音、汉字、句子这三块设计**（古诗/成语/美句作「拓展阅读」，不抢主线）

### 2.1 三个子模块

| 子模块 | mode | 一年级重点 | 二三年级递进 |
|--------|------|-----------|-------------|
| **拼音** | drill | 单韵母 a o e；声母 b p m f | 复韵母 ai ei；整体认读 zhi chi |
| **汉字** | drill | 象形字：日、月、水、火、口、目 | 合体字：明、林、从；笔顺提示 |
| **句子** | content + drill | 3–8 字短句，跟读 + 填空 | 8–15 字，看图说一句话 |

### 2.2 一年级拼音 — 内置例文（部编版同步）

**Phase P1：单韵母（6 个）**

| **o** | 圆圆嘴巴 ooo | 喔、波 | 「o——像大公鸡打鸣喔喔喔！」 |
| **e** | 扁扁嘴巴 eee | 鹅、饿 | 「e——像大白鹅在唱歌！」 |

**Phase P2：声母（先 8 个）**

| 拼音 | 形象口诀 | 拼读例 | |
|------|---------|--------|---|
| **b** | 右下半圆 b b b | ba → 爸 | |
| **p** | 右上半圆 p p p | pa → 爬 | |
| **m** | 两个门洞 m m m | ma → 妈 | |

## 4. 数学 — 加减法为主（趣味口算）

> 用户要求：**小学基本加减法**；要多插图、图文并茂、语音、更有趣

### 4.1 年级与运算范围

| 年级 | 运算 | 数域 | 说明 |
|------|------|------|------|
| **一年级上** | 只加、只减 | 5 以内 → 10 以内 | 最入门 |
| **一年级下** | 加减混合 | **20 以内** | 部编版核心 |
| **二年级** | 加减 | **100 以内** | 整十数、进位退位 |
| **三年级** | 加减 + **表内乘除** | 乘除口诀 2–9 | 加减仍占 70% |

**默认一年级：20 以内加减法。**

### 4.2 口算题型（一年级）

| 类型 | 例题 | 图示 |
|------|------|------|
| 5 以内加 | 2 + 1 = ? | 🍎🍎 + 🍎 |
| 10 以内加 | 3 + 5 = ? | 左边 3 个 🐱 + 右边 5 个 |
| 10 以内减 | 9 - 4 = ? | 9 个气球 🎈 戳破 4 个 |
| 连加 | 2 + 3 + 1 = ? | 三堆水果 |
| 填空 | 3 + □ = 8 | 数手指提示 |
| 比大小 | 5 + 2 ○ 8 | 先算左边 |

### 4.3 趣味情境（联网教学案例提炼）

| 情境名 | 包装 | 算式例 | Bella 话术 |
|--------|------|--------|-----------|
| **小猴摘桃** | 🐵🍑 | 4 + 3 = ? | 「小猴子摘了 4 个桃，又摘 3 个，一共几个？」 |
| **喂 Bella 鱼** | 🐱🐟 | 5 - 2 = ? | 「Bella 有 5 条鱼，吃了 2 条，还剩几条？」 |
| **数字骰子** | 🎲🎲 | 3 + 4 = ? | 「两个骰子：3 和 4，加起来是？」 |
| **彩虹算式** | 🌈 | 6 + 2 = 8 | 答对后数字变彩虹色 |
| **接龙碰碰车** | 🚗 | 4+3=7 → 7+2=9 | 上一题答案作下一题开头 |
| **找错小侦探** | 🔍 | 5+3=7 ❌ | 「哪道题算错了？帮 Bella 找出来！」 |

### 4.4 数学 UI（图文并茂 + 语音）

```
┌─────────────────────────────┐
│  🐵 小猴摘桃                 │
│                             │
│   🍑🍑🍑🍑  +  🍑🍑🍑  = ?   │
│                             │
│      4   +   3   =   ?      │  ← 同步大字算式
│                             │
│  🔊 「4 加 3 等于几？」       │
│                             │
│  [1][2][3][4][5][6][7]      │
│  [8][9][0]     🎤 语音答     │
│                             │
│  连对 2 题！Bella 开心~ 😺   │
└─────────────────────────────┘
```

**答对反馈：**

- 宠物切 `happy` mood + 撒花动画
- 🪙 +1，连对 5 题 + 小成就「口算小能手」

**答错反馈：**

- 「没关系，再想想~ 可以用手指数一数哦！」
- 可选「看提示」：显示手指图或实物计数

### 4.5 应用题（一年级，内置 ≥15 道）
