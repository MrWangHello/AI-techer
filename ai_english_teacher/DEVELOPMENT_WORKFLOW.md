# 项目开发规范

## 原型页面更新流程

### 触发条件
当用户说"想看外部页面"、"更新原型"、"查看界面效果"等类似表述时，执行以下流程。

### 执行步骤

#### 步骤 1：更新原型页面
- 根据最新的代码实现，更新 `/workspace/ai_english_teacher/prototype.html` 文件
- 确保原型页面反映最新的功能和界面变化
- 包含所有主要页面的完整交互逻辑

#### 步骤 2：启动预览服务
- 启动 HTTP 服务器：`python3 -m http.server 8080`
- 使用 `OpenPreview` 工具打开预览页面
- 确保用户可以在当前界面看到交互效果

### 原型页面要求
- 移动端适配（max-width: 414px）
- 完整的页面导航逻辑
- 所有主要页面的交互效果
- 响应式布局
- 流畅的页面切换动画

### 当前原型包含的页面
1. 首页 (home-page)
2. 学习页 (learning-page)
3. 课程详情页 (lesson-page)
4. 宠物页 (pet-page)
5. AI 对话页 (chat-page)
6. 设置页 (settings-page)

## 代码开发完成后的检查清单

- [ ] 核心功能实现完成
- [ ] 原型页面已更新
- [ ] 预览服务已启动
- [ ] 用户可以在界面中看到交互效果

## 注意事项

1. 原型页面应该独立于 Flutter 代码，使用纯 HTML/CSS/JS 实现
2. 原型页面应该展示真实的交互效果，而不仅仅是静态界面
3. 每次重大功能更新后，都应该同步更新原型页面
4. 预览服务使用端口 8080
